# Teaching deck

[Download the editable PowerPoint](Rules_and_Purpose_Lab_Teaching_Deck.pptx)

Seven slides introduce Rules & Purpose Lab before the [20-minute workshop](../workshop.md). Allow roughly 5–8 minutes for the introduction. For a teaching trial, pause for participants' predictions rather than reading out every answer immediately.

| Slide | Main point | Facilitator prompt |
| --- | --- | --- |
| 1. Rules & Purpose Lab | Both forms of evidence matter | What does a passing test tell you, and what does it leave uncertain? |
| 2. Contracts and purpose | Explicit rules and task fulfillment establish different things | Which property would you check with code? Which requires judgment? |
| 3. One customer, four outcomes | Contract and purpose results can differ | Predict each release decision before discussing the table. |
| 4. Evidence can become stale | Matching old quotations do not justify reusing an old assessment | What changes when we append a claim that a refund was processed? |
| 5. The release decision | Block, Review, and Eligible have explicit evidence requirements | Why can't an average score cancel a known failure? |
| 6. The hands-on workshop | Learners predict, inspect, repair, and challenge a grader | What would make your reassessment defensible? |
| 7. The teaching trial | Learner understanding is the next evidence to collect | Can you explain why a contract pass may still lead to a blocked release? |

Speaker notes include source references and expected discussion points. Slide 3 summarizes authored fixtures, not measured model performance. Slide 4's Review outcome means the assessment is stale; it does not claim a fresh semantic grade of the new sentence. A subsequent defensible purpose assessment can block that response.

The deck reflects v0.2 at merged PR #2. It makes no claim of independent human validation or an observed live provider-backed experiment. Automated acceptance evidence concerns the lab's behavior; teaching effectiveness remains to be observed.

## Editing and accessibility

Titles, body copy, and the comparison/decision tables are native editable PowerPoint objects. The cover artwork is a decorative raster image. The deck uses DejaVu Sans; install that font or choose a suitable replacement if your presentation software substitutes it. A text-based version of the content is available in this guide and the linked workshop.

The README banner repeats the cover artwork and title, with alternative text. The project thesis and all instructions remain normal Markdown text. See [asset provenance](../../assets/README.md) for the illustration prompt.
